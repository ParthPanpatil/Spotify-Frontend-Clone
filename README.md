Spotify Frontend Clone

A responsive frontend clone of Spotify built using HTML and CSS. This project recreates the visual layout and user interface of Spotify, including the navigation sidebar, playlists, music sections, album cards, and bottom music player.

The project was created as a hands-on web development practice project to strengthen my understanding of HTML structure, CSS styling, Flexbox, Grid, positioning, responsive layouts, and UI design.

Note: This is a frontend practice project and is not affiliated with or endorsed by Spotify.
